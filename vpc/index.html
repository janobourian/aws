    EC2 ssh key-pair.¶

    SSH key-pair is by Region.

    To generate Key pair - EC2 > Network & Security > Key Pairs > Create key pair

    Create EC2 instance - EC2 > Instances > Launch instances

    Connect EC2 using putty - Open putty.exe - Configure HostName (or IP address) - Connection > SSH > Auth > Credentials (file the .ppk file) > Open - login as: ec2-user
