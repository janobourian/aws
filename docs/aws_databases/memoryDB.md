# MemoryDB for Redis

* Redis-compatible, durable, in-memory database service
* Fully managed, serverless, highly available, and secure
* Designed for applications that require microsecond read and low single-digit millisecond write latencies at any scale
* Use cases:
  * Caching
  * Session management
  * Real-time analytics
  * Gaming leaderboards
  * Geospatial applications
  * Mobile applications
  * IoT applications
  * Pub/Sub
  * Queues

* MemoryDB is a Redis-compatible database, so it supports the same data structures and commands as Redis. This means that you can use your existing Redis clients and tools to interact with MemoryDB.
* MemoryDB is designed for durability and high availability. It automatically replicates data across multiple Availability Zones (AZs) and provides automatic failover in the event of a node failure. This ensures that your data is always available and protected against loss.
* MemoryDB is a serverless service, which means that you don't have to worry about provisioning or managing infrastructure. You can simply create a MemoryDB cluster and start using it without having to worry about capacity planning or scaling.
* MemoryDB provides encryption at rest and in transit, as well as fine-grained access control
* MemoryDB integrates with AWS Identity and Access Management (IAM) for access control, allowing you to create IAM policies to control who can access your MemoryDB resources and what actions they can perform
* MemoryDB also integrates with AWS CloudTrail for logging and monitoring, allowing you to track API calls and monitor the performance of your MemoryDB clusters
